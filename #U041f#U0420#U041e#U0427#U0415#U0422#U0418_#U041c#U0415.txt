============================================================
  КЕЦ КАРЛОВО GPS - Android Проект
  Android Studio 2024.1.2 | Android 10+
============================================================

КАК ДА КОМПИЛИРАШ APK:

1. Отвори Android Studio
2. File -> Open -> избери тази папка (kez_android)
3. Изчакай Gradle Sync (може да отнеме 1-2 минути)
4. Build -> Build Bundle(s)/APK(s) -> Build APK(s)
5. APK файлът ще е в:
   app/build/outputs/apk/debug/app-debug.apk

КАК ДА ИНСТАЛИРАШ НА ТЕЛЕФОНА:
- Копирай app-debug.apk на телефона
- Разреши "Инсталиране от непознати източници"
- Кликни на APK файла

============================================================
  ФУНКЦИИ НА ПРИЛОЖЕНИЕТО
============================================================

- Зареждане на Excel файл (XLSX) директно от телефона
- Автоматично запомня файла (IndexedDB кеш)
- Търсене по ИТН номер
- ГЛАСОВО въвеждане на ИТН (работи без ограничения!)
- Карта / Сателит / Хибрид
- Детайли за всеки клиент
- Отваряне в Google Maps за навигация
- Бутон "Обнови данни" за нов Excel файл

============================================================
  ПРИ ПРОБЛЕМ СЪС SYNC:
============================================================

Ако Android Studio даде грешка при sync:
1. File -> Invalidate Caches -> Invalidate and Restart
2. Провери sdk.dir в local.properties
   (трябва да сочи към твоя Android SDK)
